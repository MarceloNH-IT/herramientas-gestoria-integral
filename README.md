# Herramientas de Automatización para Gestoría Integral

Este repositorio contiene scripts y aplicaciones desarrolladas en Python enfocadas en optimizar tiempos de procesamiento, redacción legal y cálculos administrativos para gestiones de consorcios, automotores y trámites previsionales.

## 🚀 Proyectos Incluidos

### 1. Simulador de Administración de Consorcios
Aplicación interactiva desarrollada con **Streamlit** para la evaluación y simulacro de normativas (RPA CABA).
* **Tecnologías:** Python, Streamlit, Pandas.
* **Despliegue:** [Enlace a tu app en Streamlit Community Cloud]

### 2. Generador Automatizado de Descargos
Script que estructura automáticamente modelos de apelación para fotomultas de tránsito, reduciendo el tiempo de redacción repetitiva.
* **Uso:** `python generador_multas.py --dominio AB123CD --infraccion "Exceso de velocidad"`
